# 外网访问（Cloudflare Tunnel）

手机在外面也能用语音，靠 Cloudflare 的临时隧道（quick tunnel）：PC 主动出站连到 Cloudflare 边缘，Cloudflare 给一个公网 HTTPS 地址，手机访问这个地址就等于访问本机的 9880。不需要公网 IP、不需要端口映射、不需要域名、不需要备案。

**App 会自动选路**：在家走局域网直连（快、不绕公网），局域网不通就自动走隧道。两条地址配好之后，不用再手动改设置。

---

## 一、怎么用

1. 先起语音服务：`voice-server\start_voice.bat`（9880 和 9881 都要在）
2. 让隧道跑起来：`tools\start-tunnel.bat`，会把网址写进所有含 `adapter.py` 的目录，两个文件名都写
   - 想开机自动起，用「任务计划程序」把 `tools\start-tunnel.bat` 设为登录时运行即可；仓库不带自启脚本，因为路径因人而异
   - **别同时开两个 quick tunnel**，两个地址会互相覆盖
   adapter 同时认 `tunnel-url.txt` 和 `tunnel_url.txt`；也可用 `config.json` 的 `tunnel_url` 直接写死固定域名
3. App `设置 → 她的声音`：**只填「家里地址」**（形如 `192.168.1.100:9880`，`http://` 会自动补）
4. 保持「自动同步隧道地址」开着。App 在家连上局域网时，会自己从电脑把当前隧道网址记到手机里 —— 不用手动抄，打开 App 等几秒就行
5. 点「重新检测」，在家应显示「家里 通，隧道 通｜现在走 家里」；出门后会自动变成「现在走 隧道」

隧道窗口不要关，关了地址就失效。

> **升级到这套自动选路，要动三处**：① 把仓库 `voice-server\adapter.py` 的 `/ping` + `current_tunnel_url()` 合并进你部署目录里的 `adapter.py`（**注意保留自己按音色覆盖 `prompt_lang` 的那行**）；② 重启 adapter 让 `/ping` 生效；③ 重新构建安装 HAP。旧版 adapter 没有 `/ping`，App 会退回 `/health` 探活，选路仍能用，但不会自动同步隧道地址。

> **换了电脑**：`adapter.py`、`config.json` 和 `tools\` 下的隧道脚本要一起搬；`adapter.py` 读的是**自己同目录**的 `tunnel-url.txt`，所以网址文件必须和 adapter 放一起（或用环境变量 `VOICE_TUNNEL_URL_FILE` 指定）。

> **用了固定域名（命名隧道）**：把地址填进「外网地址」，并切到「我用手填的」，免得被临时隧道地址覆盖。也可以在 `config.json` 里写 `"tunnel_url": "https://voice.你的域名"`，让所有在家连过的手机都同步这个固定地址。

## 二、在家 / 出门怎么自动切换

### 判定方式：探活，不猜你在哪

不读 Wi-Fi 名字（HarmonyOS 上拿 SSID 要系统级权限，换个 Wi-Fi 也不准），而是直接问服务在不在：

| 步骤 | 动作 | 超时 |
|---|---|---|
| 1 | 打家里地址的 `GET /ping`（adapter 里不查 GPT-SoVITS，局域网几十毫秒就回） | 1.2 秒 |
| 2 | 通 → 走**家里直连** | |
| 3 | 不通 → 打隧道地址的 `/ping`，通 → 走**外网隧道** | 6 秒 |
| 4 | 两条都不通 → 语音降级成文字气泡，打字聊天不受影响 | |

- 选路结果缓存 **60 秒**，回到前台立即重选，不会每次说话都去敲门
- 某次 `/tts` 或 `/asr` 请求失败，会**当场换另一条路重试一次**，所以刚出门/刚进门那一下用户基本无感
- 设置页「当前：…」实时显示现在走哪条；「重新检测」会把两条路各测一遍

`VoiceService.ets` 里所有这些逻辑对外只有 `activeHost()`：原有的按句合成、缓存、录音转写一行都不用改。

### 隧道地址怎么自己跑到手机里

quick tunnel 每次重启都换域名，以前得手动抄。现在这条链是全自动的：

```
tools\start-tunnel.bat（或你自己包的开机自启脚本）
   └─ 抓 cloudflared 输出里的网址
        └─ 写 adapter 同目录的 tunnel-url.txt（或 tunnel_url.txt）
             └─ adapter 的 /ping、/health 返回 {"tunnel_url": "https://..."}
                  └─ App 在家探活时读到 → 存进 preferences 的 voiceWanHost
                       └─ 出门直接用
```

App 每 30 秒 tick 一次（内部 60 秒缓存，很轻）以及每次回到前台都会顺手刷新。全程**不经过任何第三方服务、不需要域名、不需要重新打包 App**。

`tools\start-tunnel.bat` 停掉时会清空网址文件，避免手机拿到过期地址一直试。桌面上原来那个「复制 VoiceServer-Address.txt 到 App」的流程现在可以不用了。

## 三、两个参数不能去掉

启动命令（现在由 `tunnel_watch.py` 代为执行，参数没变）：

```
cloudflared.exe tunnel --url http://127.0.0.1:9880 --no-autoupdate --edge-ip-version 4 --protocol http2
```

加了这两个参数才是能用的，原因都是实测出来的：

**`--edge-ip-version 4`**
部分家用路由器的 DNS 在应答 `_v2-origintunneld._tcp.argotunnel.com` 的 SRV 时，会给 `region2.v2.argotunnel.com` 返回 AAAA 记录 `::`（全零，非法地址）。cloudflared 用 Go 的解析器读这个包会直接报
`lookup argotunnel.com: dnsquery: Bad DNS packet` 然后退出。强制只问 A 记录就绕过去了。
（实测：同一个网络里，光猫的 DNS 返回是干净的，只有 A 记录；问题出在中游那台路由器上。换路由器或改 DNS 也能解。）

**`--protocol http2`**
部分家宽的 UDP 7844 不通（QUIC 连不上），走 TCP 443 的 HTTP/2 才通。

## 四、实测数据

| 项目 | 结果 |
|---|---|
| 边缘节点 | lax10（洛杉矶） |
| `/health` 往返中位数 | 约 1.3 秒（有一次 13 秒的冷启动毛刺） |
| `POST /tts`（一句 9 个字，sweet） | 200，audio/wav，147 KB，5.1 秒（含 GPU 合成） |
| `POST /asr`（3.5 秒 wav） | 200，`{"text":"今天好累想早点休息。"}`，3.5 秒 |

延迟大头是国内到 Cloudflare 边缘的这段（走了洛杉矶），不是本机。**这正是要在家走局域网的原因**：局域网 `/ping` 是毫秒级，`/tts` 也不用绕地球一圈。

## 五、限制

- **出门前得在家连过一次**：隧道网址是趁手机还连着局域网时同步过去的。如果人在外面时电脑重启了隧道，手机里还是旧网址 —— 这时手动把窗口里的新地址填进「外网地址」，或者回家打开一次 App 让它刷新。想彻底免掉这个麻烦就上命名隧道（固定域名）。
- **没有可用性保证**：Cloudflare 对无账号隧道明确写了不保证 uptime，也不建议用于生产。
- **完全公开**：谁拿到这个地址都能调 `/tts` `/asr`，等于白用你机器上的显卡和电费。地址是随机词，不容易猜，但日志、截图、路由器记录都可能泄露 —— 所以鉴权必须开着。

## 六、鉴权

隧道是公网地址，谁拿到都能调 `/tts` `/asr`，所以加了共享密钥。

- 电脑侧：`config.json` 的 `"token"`，调 `auth_ok()` 校验 `X-Voice-Token` 请求头
- App 侧：`VoiceService.tokenValue`，`/tts` 和 `/asr` 都带上这个头
- 两边必须**完全一致**

| 端点 | 要密钥吗 |
|---|---|
| `GET /ping` | 不要（App 探活不带密钥，泄露的也只有"服务在不在"和隧道网址） |
| `GET /health` | 不要 |
| `POST /tts` | 要，错了返回 401 `{"error":"token 不对"}` |
| `POST /asr` | 要，同上 |

当前的值见自己机器上的 `local/SECRETS.md`（仓库里不写明文）。

**改密钥**：`config.json` 里改 `token`，App 端改 `rawfile/app_secrets.json` 的 `voiceToken`（或直接在设置 → 她的声音 → 语音口令里填，改完立刻生效），再重启 adapter。

**关掉校验**：把 `config.json` 的 `token` 改成空字符串 `""` 即可（adapter 启动时会打印一条 warn 提醒）。

> 注意上线顺序：**先装新 App，再重启 adapter**。
> 旧 App 不带密钥，adapter 一旦启用校验就会 401。

## 七、想再往上走

1. **固定域名**：买个十几块的 `.top`，托管到 Cloudflare，用命名隧道，地址固定成 `voice.你的域名`，还能装成 Windows 服务开机自启。配好后把 App 切到「我用手填的」，就再也不用同步网址了。
2. **嫌 1.3 秒慢**：根因是出口绕到洛杉矶。如果有真公网 IPv4，直接端口映射能把往返压到 10ms 级；或者把 IPv6 打开，用 IPv6 直连。
