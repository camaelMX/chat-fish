# 外网访问（Cloudflare Tunnel）

手机在外面也能用语音，靠的是 Cloudflare 的临时隧道（quick tunnel）：PC 主动出站连到 Cloudflare 边缘，Cloudflare 给一个公网 HTTPS 地址，手机访问这个地址就等于访问本机的 9880。不需要公网 IP、不需要端口映射、不需要域名、不需要备案。

## 怎么用

1. 先起语音服务：`D:\voice-server\start_voice.bat`（9880 和 9881 都要在）
2. 双击 `tools\start-tunnel.bat`
3. 窗口里出现这样一行就是好了：

   ```
   https://xxxx-xxxx-xxxx-xxxx.trycloudflare.com
   ```

4. 把这个地址填进 App 设置里的「电脑地址」，点「试一下」应该显示「通了，她的声音在线」

隧道窗口不要关，关了地址就失效。

## 两个参数不能去掉

启动命令是：

```
cloudflared.exe tunnel --url http://127.0.0.1:9880 --no-autoupdate --edge-ip-version 4 --protocol http2
```

加了这两个参数才是能用的，原因都是实测出来的：

**`--edge-ip-version 4`**
华为 AX3 的 DNS 对 `_v2-origintunneld._tcp.argotunnel.com` 的 SRV 应答里，`region2.v2.argotunnel.com` 的 AAAA 记录是 `::`（全零，非法地址）。cloudflared 用 Go 的解析器读这个包会直接报
`lookup argotunnel.com: dnsquery: Bad DNS packet` 然后退出。强制只问 A 记录就绕过去了。
（对比：光猫 192.168.1.1 的 DNS 返回是干净的，只有 A 记录；问题出在 AX3 这一层。）

**`--protocol http2`**
家里宽带到 Cloudflare 边缘的 UDP 7844 不通（QUIC 连不上），走 TCP 443 的 HTTP/2 才通。

## 实测数据（2026-10-28）

| 项目 | 结果 |
|---|---|
| 边缘节点 | lax10（洛杉矶） |
| `/health` 往返中位数 | 约 1.3 秒（有一次 13 秒的冷启动毛刺） |
| `POST /tts`（一句 9 个字，sweet） | 200，audio/wav，147 KB，5.1 秒（含 GPU 合成） |
| `POST /asr`（3.5 秒 wav） | 200，`{"text":"今天好累想早点休息。"}`，3.5 秒 |

延迟大头是国内到 Cloudflare 边缘的这段（走了洛杉矶），不是本机。

## 限制

- **地址每次重启都变**：quick tunnel 是匿名的，换一次进程换一个域名，得重新在 App 里填。想固定就升级成命名隧道（需要自己的域名 + Cloudflare 账号）。
- **没有可用性保证**：Cloudflare 对无账号隧道明确写了不保证 uptime，也不建议用于生产。
- **完全公开**：谁拿到这个地址都能调 `/tts` `/asr`，等于白用你的 3050。地址是随机词，不容易猜，但日志、截图、路由器记录都可能泄露。

## 鉴权

隧道是公网地址，谁拿到都能调 `/tts` `/asr`，所以加了共享密钥。

- 电脑侧：`config.json` 的 `"token"`，调 `auth_ok()` 校验 `X-Voice-Token` 请求头
- App 侧：`VoiceService.tokenValue`，`/tts` 和 `/asr` 都带上这个头
- 两边必须**完全一致**

| 端点 | 要密钥吗 |
|---|---|
| `GET /health` | 不要（App 探活不带密钥，泄露的也只有"服务在不在"） |
| `POST /tts` | 要，错了返回 401 `{"error":"token 不对"}` |
| `POST /asr` | 要，同上 |

当前的值：`dsv-3f9a71c4e28b5d06`

**改密钥**：`config.json` 里改 `token`，同时改 `VoiceService.ets` 的 `tokenValue`，重新打包 App，再重启 adapter。

**关掉校验**：把 `config.json` 的 `token` 改成空字符串 `""` 即可（adapter 启动时会打印一条 warn 提醒）。

> 注意上线顺序：**先装新 App，再重启 adapter**。
> 旧 App 不带密钥，adapter 一旦启用校验就会 401。

## 想再往上走

1. **固定域名**：买个十几块的 `.top`，托管到 Cloudflare，用命名隧道，地址固定成 `voice.你的域名`，还能装成 Windows 服务开机自启。
2. **嫌 1.3 秒慢**：根因是出口绕到洛杉矶。如果光猫上有真公网 IPv4，直接端口映射能把往返压到 10ms 级；或者把光猫和 AX3 的 IPv6 打开，用 IPv6 直连。
